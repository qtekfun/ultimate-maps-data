# UltimateMaps-data

Map data, by region, for [UltimateMaps](https://github.com/qtekfun/UltimateMaps): offline vector maps and the data for search and routing. They are published as *releases* of this repository; the app downloads them through `catalog.json`.

Stable catalog (always the latest version): `https://github.com/qtekfun/UltimateMaps-data/releases/latest/download/catalog.json`

## What each release contains

- `catalog.json`: the hierarchy of regions and, for the downloadable ones, the URL, size and SHA-256 of each file, plus a `base` block for the global files.
- `<region>.pmtiles`: the map to draw (Protomaps PMTiles, cut with the region's polygon; neighboring regions overlap at the border).
- `<region>.mwm`: data for search and routing (CoMaps / Organic Maps format). They are installed under the original CoMaps name.
- `World.mwm`, `WorldCoasts.mwm`: global data the search engine needs.
- `SHA256SUMS`: checksums of every file.

## Origin and licenses

- **OpenStreetMap data:** © OpenStreetMap contributors, under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/). These files are derived databases and are shared under the same license; the app shows the attribution.
- **PMTiles:** extracted from the Protomaps daily planet build ([20261006](https://docs.protomaps.com/basemaps/downloads)) with [`pmtiles extract`](https://github.com/protomaps/go-pmtiles). The tiles are a product derived from OSM (ODbL).
- **`.mwm` files:** generated by the [CoMaps](https://codeberg.org/comaps/comaps) project from OSM (data version 261004, series 2026.06.28) and copied unmodified. We have found no specific terms of use for their CDN; if you are part of the project and would rather have them removed or served another way, please open an issue.
- **Region polygons:** `data/borders/*.poly` from CoMaps.
- The scripts that generate the catalog and the cuts are in `scripts/` of the app repository (`gen-region-catalog.py`, `split-pmtiles.py`).

No warranty. OSM data can contain errors and must not be used for anything critical.
